# Netflix-PowerBI-Dashboard
"End-to-End Power BI Project on Netflix Content Analysis”

## 📌 Project Overview
This project analyzes Netflix content using Power BI.  
It covers content distribution, genres, release trends, and top contributing countries & actors.  

## 📊 Dashboard Pages
1. **Overview Page**
   - Total Titles, Movies, TV Shows
   - Movies vs TV Shows distribution
   - Content added by year

2. **Genre Analysis**
   - Most common genres
   - Top 10 countries by titles
   - Top 10 actors
   - Rating breakdown by type

3. **Trend Analysis**
   - Content growth by release year
   - Content distribution by country (map)
   - Recent additions (table)

## 🛠 Tools Used
- Power BI
- Excel/CSV Dataset
- DAX for measures

## 📈 Key Insights
- Movies dominate Netflix with ~70% share.
- US & India are top content-producing countries.
- Dramas & Thrillers are the most common genres.
- Netflix content has grown rapidly since 2010.
